# Sistema de Cadastro de Amigos

Projeto de CRUD completo em PHP e MySQLi, com sistema de login e controle de sessão, desenvolvido para a disciplina de Programação Web II.

## ⚙️ Tecnologias utilizadas

- PHP
- MySQLi
- W3.CSS
- Sessões PHP (controle de login)

## 🔑 Funcionalidades

- Login com controle de sessão
- Create — cadastrar amigo
- Read — listar amigos
- Update — atualizar amigo
- Delete — excluir amigo
